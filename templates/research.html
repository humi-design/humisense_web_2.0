Method

How an open question gets closed

The same loop runs on client delivery and on the notes above.

Step one

State the failure mode

Name what goes wrong in production — an extraction that silently returns the wrong unit, an agent that stalls mid-task. A question without a failure mode is not yet a question.

Step two

Build the smallest test

A set of real documents or traces, a scoring rule, and a baseline. If we cannot measure the difference between two approaches, we do not claim one is better.

Step three

Publish the limits

Write up what the result does not cover. Most of the value is in the boundary: the input types, volumes and edge cases where the approach stops holding.

Collaboration

Bring us a problem you have not solved

If you are working on document extraction, agent reliability or evaluation and want a second implementation to compare against, tell us what you have tried. We will say plainly whether we can help.
