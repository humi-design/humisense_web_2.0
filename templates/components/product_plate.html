This is honest abstract artwork — a geometric composition derived from the product's own name, so every product gets a distinct plate and no two pages repeat. It is pure SVG: no request, no layout shift, and it scales to any size. The composition is a seeded "strata" field: stacked bands with a varying phase, cut by a diagonal and marked with orbits. The seed comes from the product id, so the same product always renders the same plate. #} {% macro product_plate(product) %} {% set seed = (product.name | length) + (product.category | length * 3) + 7 %} {% set h1 = (seed * 37) % 360 %} {% set h2 = (seed * 61) % 360 %} {% set rot = (seed * 13) % 90 %}
{% endmacro %}
